【什麼是 Haven】

Haven 是 KID 的自主 agent 系統，運行於 GMK Mini PC（WSL2，Debian）。
它是完全獨立的小型 agent 作業系統，不依賴任何外部平台。
核心推理引擎基於 Claude Code 源碼的六項設計模式重構。
透過 OpenRouter 接入 DeepSeek V4 Pro/Flash 模型。
Discord Bot + Telegram Bot 雙頻道並行，開機自動啟動。


【設計哲學】

  零循環依賴（Zero-Circular）：所有 import 為 tree/DAG
  窄接口（Narrow Interface）：每模塊只暴露最少必要符號
  顯式注入（Explicit DI）：Scheduler/Memory/Skills 透過 init 或 setter 注入
  自我修復（Self-Healing）：Circuit Breaker + Crash Journal + Heartbeat
  Test-First：每項功能伴隨完整 pytest


【六項核心設計來源】

  基於 Claude Code 源碼洩漏的六項設計模式（2026-05 取得）：

  1. ReAct Loop ── Think → Act → Observe 循環
     → 實現於 core/base_react_loop.py
     → 主 Router 繼承此類，加入 budget/tracer/task_manager

  2. Tool Registry ── 工具註冊、查找、policy 檢查
     → 實現於 core/tool_registry.py + core/tool_spec.py + core/policy.py
     → 20 tools registered

  3. Provider Chain ── 多模型 fallback 鏈
     → 實現於 core/category_router.py
     → 支援 primary → fallback → tertiary 三層鏈 + Circuit Breaker

  4. Category Router ── 按任務類型路由不同 provider
     → 實現於 core/category_router.py
     → 6 categories: FILE/ENV/MEDIA/COLLAB/MEMORY/SESSION

  5. Transport Abstraction ── 跨協定統一訊息層
     → 實現於 transport/adapter.py（TransportAdapter）
     → Discord / Telegram / Terminal 共用同一 Adapter

  6. Task Manager ── 持久化背景任務
     → 實現於 core/task_manager.py
     → disconnect 自動保存，reconnect 自動恢復

          AI+COMMUNICATION→COLLAB, EXTERNAL→MEMORY

          client.py (stdio/SSE), discovery.py (工具探索+prefix),
          registry.py (Bridge attach/detach)

  ──  2026-06-11 晚間新增 ──

  fcntl 雙開防護  main.py 啟動時原子鎖
          fcntl.flock(LOCK_EX|LOCK_NB) 於 /mnt/z/Haven/haven.lock
          防止雙實例撞 Discord token / Telegram

          defense in depth：外層 haven_tmux.sh pkill + 內層 fcntl

  HAVEN_LISTEN_GUILDS  成個 server 免 @mention
          設定 guild ID，所有頻道自動回應
          與 listen_channels 互補（精細 vs 全域）

  HAVEN_SHOW_TOOL_CALLS  直播工具調用過程
          Router.process() → on_progress → Discord 即時顯示
          ⚙️ tool_name arg1=v1 arg2=v2

          _active.pop() guard，防止 concurrent session 撞崩

【MCP Protocol（P6）】

  支援 MCP（Model Context Protocol）工具擴展：

  MCPBridge:          管理多個 MCP server 的生命週期
  MCPStdioClient:     JSON-RPC over subprocess stdio
  MCPSseClient:       JSON-RPC over HTTP SSE
  discover_tools():   自動探索 server 工具 → ToolSpec（prefix: mcp__<server>__）
  _build_handler():   工具名 → async handler（call server tool）

  Config 格式：
    {"name": "filesystem", "transport": "stdio", "command": "python", "args": ["server.py"]}
    {"name": "github",     "transport": "sse",   "url": "http://localhost:8765/mcp"}


【數據流完整路徑】

  使用者訊息 → Transport (Discord/Telegram/Terminal)
              → TransportAdapter.handle_message()
              → CommandHandler.dispatch()        ← 攔截 /goal /cron
              → Router.process()
                → SystemPromptAssembler.build()   ← 5-layer prompt
                → Memory context injection
                → Provider chain (primary → fallback → tertiary)
                → Tool execution (via CategoryRouter)
                  → Advisor consultation (if uncertain result)
                  → Skill lazy-load (via skill_tool)
                → BudgetTracker.record()
                → Response back to Transport

  排程週期：
    Scheduler._watcher()
    → Scheduler._tick()
    → Scheduler._dispatch(record)
    → TransportAdapter.route_to_transport()

【環境變數（.env）】

  所有設定以 HAVEN_ 為前綴，由 main.py 統一載入。

  HAVEN_OPENROUTER_KEY       OpenRouter API key（primary）
  HAVEN_FALLBACK_KEY         OpenRouter fallback key
  HAVEN_ARK_KEY              Ark tertiary key（seed-2-0-lite）
  HAVEN_DISCORD_TOKEN        Discord bot token
  HAVEN_TELEGRAM_TOKEN       Telegram bot token
  HAVEN_HEARTBEAT_INTERVAL   心跳間隔（秒，default 30）
  HAVEN_HEARTBEAT_THRESHOLD  故障判定次數（default 3）
  HAVEN_NO_TERMINAL          禁用終端（1 = background mode）
  HAVEN_OLLAMA_MODEL         本地視覺模型（default minicpm-v）
  HAVEN_LISTEN_CHANNELS      免 @mention 頻道（逗號分隔 channel ID）
  HAVEN_LISTEN_GUILDS        免 @mention 伺服器（逗號分隔 guild ID）
  HAVEN_SHOW_TOOL_CALLS      直播工具調用（1=開，0=關）


【啟動流程】

  main.py:
    1. 載入 .env
    2. 建立 Config（25 typed fields from env）
    3. 建立 Provider chain（primary → fallback, circuit breaker）
    4. 建立 CategoryRouter（vision provider: Ollama minicpm-v）
    5. 建立 LongTermMemory + SkillStore
    6. 建立 GoalManager + CommandHandler
    7. 建立 SystemPromptAssembler（5層 + goal injection）
    8. 建立 Router（所有元件注入）
    9. Router.restore_tasks()（背景任務恢復）
    10. command_handler.set_scheduler(router.scheduler)
    11. router.start_scheduler()（排程引擎啟動）
    12. 啟動 transports（Discord + Telegram + Terminal）
    13. 啟動 HeartbeatMonitor
