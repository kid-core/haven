【系統架構】

agent/
  core/          主迴圈（generator 模式，5 階段 pipeline）
                 model.py 含 MockModel 和 DeepSeekModel
  permissions/   權限管理器（3 層檢查）+ 拒絕追蹤器
  compaction/    壓縮管道（3 級，circuit breaker 保護）
  tools/         郵件 + 掃描 + ToolSearch（延遲載入）
  memory/        KairosMemory（3 層閘門，append-only 日誌）
  avatar/        系統化身（5 項數值，7 種姿態，ASCII）

lib/
  circuit_breaker.py  斷路器
  config.py           設定管理
  logger.py           結構化日誌


【處理流程】

輸入 → 壓縮(3級+CB) → 思考(DeepSeek) → 檢查(3層權限)
     → 執行(CB保護) → 處理(+驗證) → 輸出


【子系統詳解】

1. AgentLoop 核心迴圈
   generator 模式，每次 turn() 產出 5 個階段。
   支援暫停/恢復，JSON 序列化。
   最大輪次 100 保護。

2. 權限框架
   3 層檢查：規則（O(1)）→ Hook → 預設拒絕。
   拒絕追蹤器：連續 3 次或累計 20 次拒絕 → 自動降級。

3. 壓縮管道
   3 級壓縮，便宜先做：
   L1 截斷 → L2 選擇清理 → L3 LLM 摘要（CB 保護）

4. ToolSearch 延遲工具載入
   核心工具預設可見，deferred 工具按需搜尋載入。

5. 驗證 Agent
   獨立程式碼驗證器，不信任主 agent。
   「程式碼看起來是對的」→ 讀不等於驗證，跑一次。

6. KAIROS 記憶系統
   3 層閘門控制 consolidation：
   時間(24h) → Session(5個) → Lock(檔案鎖)
   Lock mtime = 時間戳，天然 rollback。

7. 系統化身
   5 數值對應真實系統指標。
   7 種姿態。夜間自動睡眠。

v0.4+ 演進（2026-06-10）
架構加固與測試體系擴充

【P0 — 關鍵架構加固】

新增 core/circuit_breaker.py：
  每 provider 獨立斷路器（CLOSED → OPEN → HALF_OPEN）
  3 次連續失敗 → OPEN，30s 後 HALF_OPEN
  試一次：成功 → CLOSED，失敗 → OPEN

新增 core/tracer.py：
  每 process 一個 trace_id
  每轉 span timing（provider call, tool call）
  process() 結束時 log_summary()


【P1 — 高優先改善】

1. TransportAdapter 抽象化（transport/adapter.py）
   DiscordAdapter + TelegramAdapter 統一 pipeline
   handle_message()：whitelist → mention strip → router.process

2. Concurrent 測試
   多 session 獨立 context，多 turn tool call 場景

3. Startup health check
   BaseProvider.ping() method（FakeProvider：no-op，HttpProvider：lightweight call）
   Router init 時 fire-and-forget 逐個 ping，log OK/TIMEOUT/FAIL


【P2 — 中優先改善】

1. Config 結構化（core/config.py）
   HavenConfig frozen dataclass，25 typed fields
   全部 os.getenv 集中管理（10 modules → 1 singleton）
   API keys 留 .env（12-factor 原則）

2. 記憶淘汰機制
   LongTermMemory.evict() 雙策略：TTL（30d）+ LRU（1000 max）
   add() 後自動觸發 eviction

3. GMK 資源管理測試
   RAM pressure 全 range 測試（0-100%）
   Disk check graceful fallbacks（psutil missing / FileNotFound / PermissionError）

4. Error recovery
   All providers down → 友善錯誤訊息（修復 empty provider list crash bug）
   Provider timeout → fallback 接手
   Circuit breaker all open → 仍回應


【P3 — 測試覆蓋擴充】

1. SkillFactory + SkillRefiner
   observe()/sanitize/pattern detection/generate/approve_all/inject_active
   evaluate()/auto-deprecate/health_report

2. Policy framework
   ToolPolicy（enable/confirm/rate_limit/timeout）
   RateLimitTracker（per-tool cooldown）
   ToolProfile（SAFE/CODING/READONLY）

3. MessageBus + BackgroundAgent
   Priority queue（ALERT > NORMAL）+ FIFO
   Mailbox cap（overflow drop oldest）
   BackgroundAgent ReAct loop + progress reporting

4. E2E test suite
   真實 tmp_path filesystem、session persistence、tool call multi-turn、clear history
