# 🏥 中醫診所管理系統 (TCM Clinic System)

> 建立日期：2026-06-02
> 狀態：📝 構想階段 — 待 Discord #tcm-clinic-dev 頻道深入討論

---

## 專案概述

一套整合型的中醫師辦公平台，涵蓋：

- 診症處方
- 病歷管理
- 藥物庫存管理
- 收費系統
- 病人資料管理

## 目標使用者

1. **第一層（MVP）：** 自己用，兼顧極簡需求的年長中醫師
2. **第二層：** 預留空間給年輕醫師的進階功能
3. **第三層：** 產品化、可重複部署

## 規模估算

- 每日診次：30-40
- 病歷總量：20,000 - 50,000 名病人記錄

## 技術選型（初步建議）

- **後端：** FastAPI (Python)
- **前端：** HTMX + Tailwind CSS（快速開發，老醫師友善）
- **資料庫：** PostgreSQL（考量未來多人 + 報表需求）
- **部署：** Docker Compose

## Phase 1 核心功能（4-6 週）

核心看病流程：

```
掛號 → 看診（症狀→辯證→處方）→ 結案
```

包含：
- 📋 病人建立 + 基本資料
- 🩺 診症記錄（主訴、四診、辯證）
- 💊 處方編輯器（藥名聯想、常用方、劑量）
- 📄 病歷時間線
- 🔍 病人搜尋

不放的：庫存管理、收費、報表、多用戶

## UI 設計原則（老醫師友善）

- 預設大字體 20px+
- 線性工作流，非並排 dashboard
- 鍵盤快捷鍵優先
- 藥名聯想搜尋、常用方一鍵帶入
- 每步都有「上一步」
